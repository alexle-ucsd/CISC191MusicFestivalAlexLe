**Java Programming Project | CISC 191 – Mesa College**

**Developer:** Alex Le  
**Language:** Java  
**Technologies:** Java Swing, Object-Oriented Programming (OOP), Eclipse IDE, Git, GitHub

## Project Overview

The Electronic Music Festival Management System is a Java desktop application designed to simulate the management of a large electronic dance music festival.

The application features a colorful, neon-themed graphical user interface (GUI) and allows users to explore festival information, register attendees, purchase tickets, view DJ lineups, and search for artists.

This project demonstrates my ability to apply Java programming concepts to a practical software application.

## Main Features

- **Register Attendee:** Register festival attendees and manage their information.
- **Buy Ticket:** Select festival ticket types, including General Admission and VIP.
- **View Lineup:** Browse DJs and artists performing at the festival.
- **View Schedule:** Explore artist performances by festival day and stage.
- **Search Artist:** Search for a DJ and display their performance details, including date, stage, and set time.
- **Exit:** Close the application.

## Festival Information

- **17 festival stages**
- **3 festival days:** Friday, Saturday, and Sunday
- **Electronic dance music performances**
- **Custom stage names**, including House Pineapple and Remote Box
- **Artist schedules** with performance dates and times

## Project Structure

The application includes the following Java classes:

- `FestivalGUI.java` – Graphical user interface
- `Festival.java` – Festival information and management
- `Artist.java` – Artist information
- `Attendee.java` – Attendee registration
- `Ticket.java` – Ticket information
- `Stage.java` – Festival stage information
- `Performance.java` – Artist performance schedules
- `FestivalTest.java` – Project testing

## How to Run

1. Download or clone the GitHub repository.
2. Open the Java project in Eclipse IDE.
3. Make sure the Java Development Kit (JDK) is installed.
4. Open `FestivalGUI.java`.
5. Run the application as a Java Application.
6. Use the main menu to explore the festival management features.
